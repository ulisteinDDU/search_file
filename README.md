# 可视化文件查找工具（FileSearchTool）

纯 C（Win32 API，无第三方依赖）的 Windows 桌面小工具：**按文件名查找** 与 **按文本内容查找** 双功能合一，TAB 选项卡切换，窗口可自由缩放，支持 Win7 / Win10 / Win11（x64）。

## 快速使用

直接双击运行 `FileSearchTool.exe`（约 180 KB，单文件绿色软件，自带程序图标）。

### 功能一：按文件名查找（第一个 TAB）

1. **查找目录**：点击"浏览…"打开现代文件夹选择器（地址栏可直接复制/粘贴路径），或直接输入路径；下次打开自动定位到上次选择目录，程序启动时也会自动回填；
2. **文件名**（必填）：包含匹配（默认，也可选"全字匹配"）文件的基本名或完整文件名；
3. 可选：**区分大小写**、**后缀**（下拉**可多选**：点击追加、再点移除，预设含 Office 文档 doc/docx/xls/xlsx/ppt/pptx 等；也可手工输入如 `txt;md;cpp`，"全部"=不过滤）；
4. 点击"开始查找"（或直接按 **回车**），递归查找所有子目录；
5. 结果列：序号 / 文件名 / 扩展名 / 大小 / 修改时间 / 所在目录；**点击"修改时间"表头可按时间升/降序排序**（再点切换方向，表头有 ▲/▼ 指示；重新查找或过滤后恢复默认顺序）。

### 功能二：按内容查找（第二个 TAB）

1. 选择目录，在"查找内容"输入要查找的字符串（必填，整串作为子串精确匹配，不支持通配符）；
2. 可选：**区分大小写**、**常用文本格式**（约 90 种：txt/log/c/cpp/py/java/html/json/md/sql/bat/…，含 Makefile 等无扩展名文件，悬浮可看说明）、**自定义后缀**（下拉多选或手工输入，与常用格式取并集；输入 exe/jpg 等非文本后缀会提示）；
3. **字符集**多选勾选：UTF-8 ☑ / GBK/GB18030 ☑ / Big5 ☐ / UTF-16LE ☐（默认勾选前两项）；无 BOM 文件按勾选的字符集逐一尝试、任一命中即算（如 UTF-8 的 .md 与 GBK 的 .sql 默认即可一次同时命中）；带 BOM 的文件始终按 BOM 解码；全部取消勾选则无法开始查找；
4. **结果实时显示**：命中的行随扫描进度逐批出现在列表中（约 0.1 秒级），无需等整个目录扫完；随时"停止"保留已显示部分；
5. 结果列：序号 / 文件绝对路径 / 行号 / 匹配行内容。

### 通用操作

| 操作 | 说明 |
|---|---|
| TAB 切换 | 点击页签，或快捷键 **Ctrl+Tab** / Ctrl+1 / Ctrl+2 |
| 帮助菜单 | 菜单栏"帮助"：功能说明（**F1**）/ 查找与匹配规则 / 字符集说明 / 常用快捷键 / 关于 |
| 清空 | 每页右上"清空"按钮：恢复本页全部默认选项（目录/内容/过滤/大小写/匹配模式=包含/后缀/字符集/每页 100）并清除查找结果 |
| 二次过滤 | "过滤"框输入关键字（路径或行内容，不分大小写）后回车或点"过滤"，"清除"恢复 |
| 分页 | 每页可选 30/50/100/200/500/1000 条（**默认 100**，自动钳制 30~1000）：下拉切换即生效；**手工输入后回车或点其他处（失焦）生效**；首页/上一页/下一页/末页 |
| 结果总数 | 列表上方"共 N 条"（过滤时显示"共 N 条（已过滤，全部 M 条）"） |
| 双击结果 | 在资源管理器中定位并选中该文件 |
| 右键结果 | 复制完整路径 / 打开所在位置 / 复制行内容（功能二） |
| 停止 | 查找中可随时点击"停止"，已找到的部分结果会保留 |
| F5 | 重新执行当前页的查找 |

## 构建方法

```
build.bat        （内部调用 D:\soft\tools\mingw64 的 gcc/windres）
```

产物：`FileSearchTool.exe`（`-static` 链接，无 MinGW 运行库依赖）。

## 运行环境说明（Win7）

- Win10 / Win11：**开箱即用**，无需任何运行库；
- 纯净 Win7（未装过更新）：需一次性安装微软官方 **VC++ 2015-2019 Redistributable (x64)** 或 KB2999226（Universal CRT），之后即可正常运行。

## 自测

```
FileSearchTool.exe --selftest
```

在临时目录自动构造用例（大小写 / 全字与包含 / 后缀过滤含命中与排除及多后缀 / 中文 UTF-8 / UTF-16LE / 自定义后缀 / 字符集强制与多选：GBK·UTF-8·Big5、BOM 优先级、默认掩码下 GBK 的 .sql 与 UTF-8 的 .md 同时命中、结果容器随任务预创建等），两套引擎 19 项校验，结果写入 `selftest_result.txt`，退出码 0 表示全部通过。

另有 GUI 分页回归测试 `powershell -ExecutionPolicy Bypass -File _pagetest.ps1`（自动构造 100 个文件，校验每页切换、翻页按钮、手工输入每页条数等 5 项断言；测试过程中的弹窗会被自动关闭）。


## 已知限制

- 结果条数上限 100 万条（达到后提前停止并在状态栏提示）；单个文本文件 > 512 MB 跳过；
- 匹配行内容最多显示 512 字符（超长截断加 `…`）；同一行多次命中只计 1 条；
- 不支持 UTF-16BE 文件（极少见）；大小写折叠仅覆盖 ASCII（中文不受影响）；
- 无扩展名文件（如 Makefile）仅在勾选"常用文本格式"时纳入内容查找。
